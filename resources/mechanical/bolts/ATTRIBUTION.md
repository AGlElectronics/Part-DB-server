# BOLTS metadata attribution

The standard names, available metric sizes, coarse thread pitches, and common
lengths in `catalog.json` are a metadata-only subset derived from:

- BOLTS — Open Library of Technical Specifications
- <https://github.com/boltsparts/boltsparts>
- Upstream revision: `5c83300a57761f70db87f50c9a1f647c7278a4c2`
- Data files: `hex_socket.blt`, `hex.blt`, `nut.blt`, and `washer.blt`

- Original author: Johannes Reinhardt and BOLTS contributors

The original CAD generators and backend code are not included. The Part-DB
adapter and normalization code remain licensed under AGPL-3.0-or-later.

The data is provided without warranty. Standard designations identify product
families only; users must verify dimensions and requirements against the
applicable official standard before engineering use.
